## Node 26 support {#node26}

Modules using the 1.x API can now declare `node26` as their runtime, by setting `runtime.type` in `companion/manifest.json`:

```json
{
  "runtime": {
    "type": "node26",
    "api": "nodejs-ipc",
    "apiVersion": "0.0.0",
    "entrypoint": "../main.js"
  }
}
```

This is the only change in this release.

### Why? {#why}

Due to multiple major CVEs in Node 18, which will not be fixed upstream, the `node18` runtime is now end-of-life in Companion. Modules still using it need somewhere to move to.

Modules on the 1.x API have been able to use `node22` since [API 1.11](./v1.11.md), but Node 22 itself reaches end-of-life in a few months. Previously, the only way to get `node26` was to migrate to [API 2.1](./v2.1.md). As that is a large migration, 1.15 lets modules move to a long-term supported version of Node.js without needing to adopt the 2.x API at the same time.

:::tip

If your module is still using `node18`, we strongly recommend updating as soon as possible. `node22` will work, but we recommend going straight to `node26`, as Node 22 is end-of-life in a few months. See [Updating Node.JS](../module-lifecycle/updating-nodejs.md) for guidance.

:::
